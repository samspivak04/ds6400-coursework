5 Concepts from this paper:

  • linear model: continuous outcome variable y with independent variables x subscript n where n is the number of independent variables
    • \(E[y|x1, x2, x3] = b0 + (b1x1 + b2x1^2 + b3x1^3)x3 + (b4x2 + b5x2^2 + b6x2^3)x3\), etc.
    • = b0 + {x3 = never, sum of i = 1-3 of }
    • mean E, variance V, OLS or MLE can estimate model (what is the best choice based on the data we have?)
  • generalized linear models (GLM): model we can fit when we assume the outcome is binary, Bernoulli, Poisson, binomial, etc. (logistic regression is an example); linear models generalized to distributions that are in the exponential family
  • probit analysis: assigning each variable a score based on how similar/close it is to the mean (z-scores? variance?)

  • logistic regression:
  • least squares: fitting line/curve/model/function to data (regression) by finding the residuals (true value - predicted value) of each point, then squaring the residuals (so they are positive), and adding them all up to find the total error; we want to minimize the total error to find the line of best fit (optimization)
  • weighted least squares:
  • distributions:
    • normal distribution: bell curve (continuous)
    • binomial distribution: bar chart where the x-axis is the number of positive outcomes and the y-axis is the probability of that number of positive outcomes, using multiple trials (discrete)
    • multinomial distribution:
    • Bernoulli distribution: one trial with two outcomes (discrete)
    • Poisson distribution: probability of events occuring in one (fixed) interval (discrete)
    • gamma distribution: includes the chi-squared distribution and other continuous probability distributions (continuous)

Parts of a GLM: - random component: how is the variable distributed? (normal, binary, Bernoulli, Poisson, binomial, etc.) GLMs allow this to be from the exponential family. - systematic component: linear combination of predictors (independent variables); looks like linear regression because it is of the form b0 + b1x1 + b2x2 + … + bnxn - link function: a function that connects the linear predictor to the expected value in the dataset

6 Expressing GLMs mathematically:

Usually we would express linear models as y = mx + b or some other equation that assumes all our data can fit a certain line or one of the distributions defined above. We use the same linear structure for the systematic component of GLMs: p = b0 + b1x1 + b2x2 + … + bnxn. I chose p to mean linear predictor. The b’s are the coefficients and the x’s are the variables. In linear regression, these variables would have to all be independent, but that is not necessarily the case for GLMs.

9 Special considerations for using GLMs:

GLMs are good for data that is not linear (cannot be modeled well with linear regression). It is important to consider what your data is describing before choosing a model.
